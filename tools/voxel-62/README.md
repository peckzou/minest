# Minest Duo 62 · 体素世界（工具整理 + 房间和陈列）

`iPhoneDuo62.html` 是新的独立版本：`iPhoneDuo.html`（53.85）原样不动，只在 `</body>` 前加了一段 `<script id="mn-voxel-62">`。60 和 61 也都没有改。

## 工具整理

61 的四排按钮改成两条：

- **顶栏（一行）**：✕ 回到 2D 岛 · ‹ 上一层 · 当前位置 · 👁 阅览 / 🚶 行走 / ✈ 飞行 · ↶ ↷ · 🗺 看一眼 2D 岛 · ⚙ 设置。
  - ⚙ 里有：自动旋转、控制台在旁边、精度 ×2 / ×4 / ×8、重新转换、撤销方块改动。
- **底栏（一排工具）**：👆 浏览 · ⛏ 方块 · 🧩 摆放 · 🏠 房间 · 📄 陈列 · ⛰ 地形 · ✨ Smart。
  - 点一个工具，它的选项只显示在底栏上方的一块面板里；再点一次就收起，回到浏览。
  - 方块快捷栏只在 ⛏ 方块里出现，摇杆和提示都排在面板上方。

## 🏠 房间

1. **进入建筑**：在 🏠 面板里点一座建筑，或在体素世界里点它。在 My World 里，只有 Studio 建筑和地标有房间；普通方块房子打开后是展示柜。
2. **🏗 建一座**：岛上没有能进去的建筑时，面板列出 Studio 建筑（体育馆、博物馆等）。选一座，再点体素世界里的空地，就建在那里。
3. **加房间、进房间**：进入建筑后，面板列出它的房间和「＋ 加房间」的种类（My World 推荐的在前面）。点一个房间就进去，体素世界会换成这个房间。
4. **‹ 返回**：回到建筑，再回到岛。

## 📄 陈列

- 点一张卡片，再点体素世界里的展示架，卡片就放进展示架的空位；点地面，卡片就立在那里。
- 卡片是用 My World 自己从 Box 拖出来的方式放的。拖的时候只有你点的那个展示架能接住，前面挡着的东西不会抢走它。
- 点的东西放不了卡片时，卡片会立在那块地上。
- ✦ 自动陈列：把所有列表放到合适的家具上。

## 🧩 摆放

- 📦 物件库会打开控制台的物件选择。选一个物件，它先出现在岛上（在房间里就是家具和展示架），再点体素世界的地面，它就移过去。
- 点体素世界里已有的物件可以选中它，再点地面移动它。

## 其他

- ⛰ 地形和 ✨ Smart 的用法和 61 一样。
- 所有改动都写进 My World 的岛，2D 岛同步显示，↶ 可以撤销。

## 重新生成

```
python3 tools/voxel-62/make62.py path/to/iPhoneDuo.html iPhoneDuo62.html
```
