# Minest Duo 60 · 体素世界

`iPhoneDuo60.html` 是一个独立的新版本，基于 GitHub `peckzou/minest` main 分支最新的 `iPhoneDuo.html`（Minest Duo 53.85）。原文件一个字节都没改，只在 `</body>` 前加了一段 `<script id="mn-voxel-60">`。`tools/make60.py` 生成时会检查：去掉这段脚本后，新文件和原文件完全相同。

## 用法

1. 打开 My World 里的任意一座岛，或者进入某个房间。
2. 点左下角「🧊 体素世界 60」。
3. 当前场景会被转换成真正的方块世界：
   - **阅览**：环绕查看。拖动旋转，滚轮或双指缩放，右键或 Shift 拖动平移，🔄 自动旋转。
   - **🚶 行走**：WASD 或摇杆移动，拖动看四周，空格或 ⬆ 跳；遇到半格高的台阶会自动走上去，门可以穿过。
   - **✈ 飞行**：F 键切换，⬆/⬇ 升降。
   - **⛏ 挖 / 🧱 放**：点一下方块就挖掉或放置。快捷栏里是这座岛用得最多的 9 种方块，可以用 1-9 选择。
   - **精度 ×2 / ×4 / ×8**：每个世界格转换成几个体素。默认 ×4。
   - **↻ 重新转换**：岛改了之后重新生成。**⟲ 撤销改动**：清掉你挖和放的记录。
4. 挖和放的改动保存在本机 localStorage（键名 `minest.vx60.*`），按岛、场景和精度分开存。
5. Duo 半折叠时（`duo-halfopen`），体素世界显示在上屏，摇杆、按钮和快捷栏在下屏。

一键圣托里尼本身已经是 Oia 体素世界，所以会直接打开它。

## 转换原理

体素层会在后台按一次 My World 自己的「🚶 Walk in」，读取它建好的 three.js 场景，然后关掉。读到的内容包括地形、山、河、湖、建筑、Studio 模型、人和动物。读取时 Walk in 的画面被隐藏，用户看不到。

接着把每个面按半个体素的间距采样，写进体素网格：

- **带 Minecraft 贴图的方块零件**：保留原贴图，作为方块的面。
- **模型和纯色零件**：从它们自己的贴图或颜色取样，变成颜色方块。
- **地面**：在地形下面填实，岛底加一层石头。
- **水**：往下多挖一层，看起来有深度。
- **门**：可以穿过。
- **图片和招牌**：保留成面板。

渲染方式：16×16 区块，面剔除，角落环境光遮蔽（AO），简单天光，方块云。

借鉴了 mūse 的 `voxel.html`：顶层 popover 覆盖层、环绕视图、只读访问 App 数据。也借鉴了 Oia 体素引擎：区块化方块世界和行走、飞行、建造的操作。
