# 🏔 Alpine Chalet · 阿尔卑斯木屋 3D 体素场景

这是一个独立的新场景，没有修改圣托里尼（Oia）世界、威尼斯，也没有修改任何陈列 / 体素世界 60–63 的页面。

## 包含的文件

| 文件 | 说明 |
|---|---|
| `alpine.html` | 独立的场景页面，可以直接打开 |
| `alpine-world/world.js` | 新写的世界生成器：雪山、草坡、松林、湖泊、溪流、石板路，以及 12 座带室内的建筑 |
| `alpine-world/textures.js` | 新的 16×16 像素贴图，共 30 种，和 Venice / Oia 用同一种图集机制 |
| `alpine-world/mesher.js`、`alpine-world/app.js` | 由 `port_app.py` 从 `venice-world/` 引擎移植过来 |
| `iPhoneDuo64.html` | `iPhoneDuo.html` 加上阿尔卑斯集成后的新页面，由 `patch_alps.py` 生成，源文件只读不改 |
| `tools/voxel-alps/port_app.py` | 引擎移植脚本 |
| `tools/voxel-alps/patch_alps.py` | 把场景集成进 My World 的脚本 |

## 复用了什么

`port_app.py` 把现有引擎移植过来，下面这些全部沿用：
- 渲染器、天空与昼夜循环、方块云、星空
- 分区块网格（面剔除、AO）、PCF 阴影
- 第一人称物理、村民人群、飞鸟、旗帜
- 小地图、地标横幅、导览镜头、快捷栏、触屏摇杆、拆方块 / 放方块

做了以下替换和新增：
- **去掉**：贡多拉和船、鸽子、Sketchfab 模型库。这次不接入第三方 API，所以没有加载 GLTF。
- **水面**：原来是无限大的海面，改成只覆盖湖泊的水面。
- **村民**：只在石板路上走。
- **地标传送和导览路线**：从世界数据里自动生成。
- **新增 🚪 门**：按 E、右键或在触屏上点门可以开关，人站在门口时不会被关在门里。
- **新增 🪑 座位**：可以坐在椅子和长凳上，一移动就站起来。
- **新增壁炉火光**：用单独的常亮材质，白天也看得见火。
- **新增**：烟囱炊烟、牧场里带铃铛的奶牛、瑞士国旗。

## 场景内容（192×160×80）

- **地形**：北面是雪峰，峰顶有十字架；两侧有山脊；山谷是起伏的草坡和野花草甸；成片的松林，高处的树上有积雪；还有一条溪流和一座高山湖（带木栈桥）。
- **村庄**：广场上有木质水槽喷泉、长凳和路灯。
- **建筑**：8 座木屋、Gasthaus 旅馆（3 层）、小教堂（白墙加尖顶钟楼）、谷仓和围栏牧场、山坡上的 Berghütte 山屋。
- **木屋结构**：石砌底层，原木墙的上层，木瓦人字屋顶，红色或绿色的心形镂空百叶窗，木阳台上摆着天竺葵，烟囱，门灯。
- **木屋室内**：壁炉、地毯、桌椅、长凳、书架、吊灯；有楼梯通到楼上，楼上有床。

## 和 My World 的层级连接

在 `iPhoneDuo64.html` 里打开一座岛，在控制台点「一键生成 ▾ → 一键阿尔卑斯木屋」：
- 这座岛会变成这片山谷：地形、湖泊，以及每座建筑各对应一个物件（用 `p.alp` 关联）。
- 页面随后直接进入 3D 山谷。
- 之后再进入 3D：点控制台的「进入 3D 阿尔卑斯木屋」，或者在岛上点 🚶 Walk in / 阅览。

走到任何一座建筑的门口，点 🏠 会出现几个选项：
- **🏠 剖面 Dollhouse**：进入 My World 自己的建筑视图，层级是 World → Building → Dollhouse → Room → Display → Item。在这里可以用 ✨ Smart Room、＋ 加房间，双击房间进去，再用 Smart Display 和展品。
  - 底部有一条「🏔 回到门口」，点它或者用 ‹ 退出建筑，都会回到这座木屋的门口。
- **🚪 开门进屋**：直接走进体素木屋本身。
- **🚶 走进 My World 房间**：用 My World 的 3D 走进第一个房间，和圣托里尼的做法一样。

房间、展位、展品都存在这座岛自己的记录里，在 2D 岛上也能看到。在 3D 里拆或放的方块也随岛一起保存。

## 已验证（无头 Chromium）

- `alpine.html` 加载约 0.9 秒。
- 开门；走进木屋；坐在椅子上；从楼梯走上二楼。
- 在 `iPhoneDuo64.html` 里：
  - 一键阿尔卑斯木屋会生成 12 个关联的物件，并打开 3D 山谷。
  - 在 Edelweiss 门口完成了这一串：开门 → Dollhouse → ✨ Smart Room 确认（4 个房间）→ 双击进入房间（第 4 层）→ ‹ 回到门口。
  - 重新加载页面后，房间和放下的方块都还在。
