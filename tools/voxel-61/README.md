# Minest Duo 61 · 体素世界（融进 2D My World）

`iPhoneDuo61.html` 是新的独立版本。它和 60 一样基于 `iPhoneDuo.html`（53.85）：原文件一个字节没改，只在 `</body>` 前加了 `<script id="mn-voxel-61">`。旧的 `iPhoneDuo60.html` 没有动过。

2D My World 的所有功能都保留。体素世界是叠在它上面的一个视图，点 ✕ 就回到原来的 2D 岛。

## 61 新增

- **🎛 控制台**：体素世界只盖住岛的画面，My World 自己的控制台留在旁边。宽屏时控制台在右侧；竖屏或 Duo 半折叠时，它在下方或下屏。控制台里的工具都能直接用：Edit / 物件选择、Tools、一键生成、Smart Island、✨ Smart、🪄 Smart Fill、Suggest、Terrain、More land、Undo。
- **实时同步**：控制台（或任何地方）改了岛，体素世界大约 1–2 秒后自动重新转换，视角和人物位置不变。
- **🧩 摆放**：在控制台里放一个物件后，点体素世界的地面，它就移到那里；也可以先点一个物件选中它，再点地面。用的是 My World 自己的拖动规则：放不下时会挪到最近的空位，↶ 可以撤销。
- **📄 卡片陈列**：从这座岛的列表里选一张卡片，再点体素世界里的展示架或地面，卡片就放上去（用 My World 自己的 `display` 和放置逻辑）。
- **✦ 自动陈列**：调用 My World 的 Arrange，把每个列表放到合适的家具或展示架上。
- **✨ Smart / 🪄 Smart Fill / 一键生成 / ↶ ↷**：这几个按钮直接调用控制台的同名功能。方案在控制台里预览，✓ Confirm 后体素世界跟着更新。
- **🛠 地形**（整合 mūse 第 2 版的地形工具）：
  - ⛰ 升起、⬇ 降低、▦ 拉平、∿ 平滑、💧 造水、〰 河流、🌿 恢复。
  - 笔刷大小 1 / 3 / 5，另有 ✨ Smart 地形和 🗑 重置地形。
  - 在体素世界里点一下或拖动就能改地形。
  - 和 mūse 版的区别：mūse 版把地形改动另存在 `vxterr.v1.*`，只有体素视图能看到。61 用 My World 自己的地形笔刷，直接写进岛的地形数据（`V.d.terr`），所以 2D 岛也会显示，地形跟着岛一起保存，↶ Undo 也能撤销。
  - 拉平和平滑是用多次「升起 / 降低」实现的，笔刷边缘外的一圈格子可能会被带高或带低一级。

60 的功能都还在：阅览、行走、飞行、挖方块、放方块、×2 / ×4 / ×8 精度、Duo 半折叠布局。
