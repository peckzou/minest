# 教师改良版 v1 · 改动说明

> 基底：`minest-my-world-v3/iphone.html`（已含 My World v1 + v2 的全部改动），另存为 `minest-teaching-v1/iphone.html`，只改本文件。
> 铁律遵守情况：GitHub 仓库 `peckzou/minest` 未动；v3、v2、pristine 基线 md5 全部未变（见文末核验）；改动全部是手术式替换，未重写任何模块；未尝试发布预览（由父级发布）。

## 按任务项改了什么

### 1. 首页：主按钮"▶ 开始上课"（home，`function home()`）

- 首页原来一排 6 个按钮，现拆成两排：第一排只剩一个主按钮"▶ 开始上课"（金色、56px 高、18px 字），第二排是原来的 6 个按钮（任务原话说"其余 5 个"，实际首页有 6 个旧按钮，6 个全部降级，无一删除）。
- "开始上课"的点击逻辑与原来"学生课堂"按钮逐字相同：用同一份课程数据调 `MinestTemplates.open(b, {audience:'student', ...})`。如实说明：**课堂流程选择器（flowModal）没有从首页直达的路**——`MinestTemplates` 对外只暴露 `version/read/availability/isOpen/close/open`，flowModal 未导出，首页作用域够不到它。所以"开始上课"先落在学生课堂视图，老师在课堂视图里再开"课堂流程"。这是任务允许的兜底做法，不是流程选择器的直达。
- 改名（仅首页这两个按钮，任务指定范围）："学生课堂 V1" → "学生课堂"，"我的自学 V2" → "我的自学"。其他地方的 "Teaching V1"（5 处）未动，不在任务范围内。

### 2. 课堂工具栏 Dock（`function renderDock()`）

- **新增"⏹ 结束课堂"按钮**：常驻工具栏（工具栏只在活动页与总结页出现），直接调同模块的 `finishFlow()`。有流程时出流程总结（已完成环节 + 之前跳过的环节 + 计分 + 错词）并回词库；无流程的单个活动里点它，同样出计分与错词总结并回词库。
- **总结页不再显示流程小 chip**：原来总结页既有工具栏 chip，又有 56px 大按钮，功能重复。现 chip 只在活动页出现，总结页只剩大按钮（"进入下一环节 / 完成课堂流程"）。
- **活动页拆成两个按钮**：主按钮"🧭 N/M ✓ 完成，去下一环节"（新函数 `flowComplete`，与 `flowNext` 的总结页分支逐行相同：当前环节记为完成，再前进；到末尾则出总结）+ 次按钮"跳过本环节 ⏭"（原 `flowNext` 的活动页行为：记为跳过，再前进）。原来一个按钮在活动页叫"跳过"、在总结页叫"下一环节"，容易手滑点错，现已分开。
- **全部工具栏按钮放大到 44px**：两套主题规则都改了（tt-v72 原 34px、tt-v808 原 32px，现均为 44px 最小高度）。其余地方残留的 34px/32px 规则经核查均非工具栏按钮（是药丸标签等其他组件），未动。

### 3. 计分可见性

- 当前轮到的队伍按钮在名字后追加" · 轮到"（原有 `is-on` 高亮保留，双重标识，不只靠颜色）。
- 计分提示写清原因：`award()` 原来只提示"红队 +2"，现为"红队 +2（独立答对）"或"红队 +1（纠正后答对）"，与计分规则（独立答对 +2、纠正后答对 +1）对应。

### 4. 课堂流程选择器（`function flowModal()`）

- 每个预设行新增一行："N 环节 · 会跳过 M 个"。M 用与 `smartFlow` 相同的 `T.availability(list)` 计算：预设环节里凡是 availability 给出"不可用原因"的都算会跳过。N 为预设环节总数。
- "智能推荐"行额外说明两点：因其流程本身就是 `smartFlow` 按资料筛过的可用子集，M 恒为 0，行内标注"（已按资料自动筛选）"；另起一行给依据数字："依据：配图 X/Y · 有分类 Z 张 · 错词 W 个"，取自同一份 `M.readiness(list)`（配图 = 有自定义图的卡数 / 总卡数；有分类 = 填了明确标签的卡数）与错词本数量。
- 诚实边界：availability 只覆盖 flash、missing、reveal、disappear、quick、find、picture、wheel、tf、scramble、odd、sorting、next 这 13 个模板；listen、match、copywrite、bingo、hotseat 没有 availability 条目，一律按"可用"计，运行时若因其他原因仍被跳过，结尾总结里仍会列出。
- 小组计分 pill：0 从"关闭"改为"关"，其余仍为"N 队"。
- 流程弹窗的引导语同步更新：原来写"每个活动完成时出现'进入下一环节'"，现改为"活动中点'完成，去下一环节'，总结页出现'进入下一环节'"，与新按钮文案一致。

### 5. 一键备课面板（两个版本都改了）

- **搜图墙按钮降级**：仅 v808 版面板顶部有"🖼️ 切换到免登录'多图源搜图配图墙'"按钮，原来是 `tt-primary` 主按钮样式，现改为无背景、无边框、下划线的链接样式（文字色沿用应用青色 `#0ba5b2`），不再抢"一键生成整组"的主按钮地位。v72 版面板本来就没有这个按钮，无需改。
- **"只补缺失项"默认勾选、且尊重用户选择**：两个版本原来都是 `missing=true` 写死——每次打开都默认勾选，但用户上次取消勾选的选择不会保留。本次改为：首次打开（无存储记录）仍默认勾选；一旦用户改过勾选，立即写入本机 `minest.prep.missing`，下次打开按存储值恢复，绝不覆盖用户的明确选择。两版共用同一个存储键，偏好互通。

## 刻意暂缓（未实施，原因）

1. **自定义计时时长**：计时目前是 30/60/90 三档固定按钮；加自定义需要新的时间选择界面与 `startTimer` 的输入校验，属新界面，暂缓。
2. **自定义流程的模板分组**：20 多个模板按"认读—理解—操练—产出"分组需要重排选择器布局并补每组的说明文案，属布局重构，暂缓。
3. **点名名单同步/导入**：名单目前只存本机；同步到教学集或支持班级名单导入需要动 `TeachingSync` 与名单存储，属数据层改动，暂缓。
4. **工具栏"更多"溢出菜单**：把点名、大屏等收进"更多"需要新增菜单组件与开关状态，暂缓；本次只做了按钮放大与"结束课堂"常驻。
5. **备课入口合并为单一流程**：一键备课 / 智能备课 / 搜图墙三线合一需要重排备课导航，属流程重构，暂缓；本次只做了搜图墙按钮降级与缺失项偏好记忆。
