### 十种阅读方式分别放什么

- **翻书**：按能力分章读完整解释，先理解再答题。
- **烛光对话**：以一问一答讲清“为什么”，使用本包自编题，不能冒充专家原话。
- **霓虹书城**：每栋内容单元对应一个能力，入口显示问题和学习目标。
- **概念星图**：连接词、例子、技能和误区，关系需有名称。
- **穿越阅读**：在先修→概念→应用间移动；不用虚构历史年代。
- **金句长廊**：展示自编的短定义与边界条件，标“学习提要”，不伪称官方引文。
- **名言天灯**：用一条提取问题唤回知识，点击查看答案和来源。
- **引用榜**：只能显示文本出现或引用统计；不得用词频冒充考试权重或高频考点。
- **关联星门**：连接相关能力，例如词汇与科学说明、比例与地图。
- **问书**：当前实现是关键词检索正文句子，不是能可靠解题的推理 AI；使用可溯源的已写答案。

### 现有工具的实际限制

- 动态卡片2.0能读取Minest现有看板，普通知识、技能、术语与图解卡可以共用内容。
- 全息台支持内容消息；Obsidian支持`pages / decisions / sources / relations`知识库，适合有名称、有来源的关系。
- 当前光锥有内置科技史及人物年份接口，不是任意时间线JSON导入器。需要Claude对接真实事件；不要把掌握度、先修顺序或学习阶段当成年份。
- 纸艺小岛当前读取地形与场馆数据；折叠书当前主要读取人物、年份和介绍。它们需要内容接入，不能只改文件名便声称可运行。
- 十种阅读方式的示例包含《纯粹理性批判》专门处理；“问书”是关键词匹配正文句子，不能当可靠解题AI；“引用榜”的词频不能当考试权重。
- Sphere可选择图片、GIF或视频作为临时素材；多图分屏更适合图解，单张文字图铺满球面容易变形。

#### 901-001 口语与互动

**我能完成的任务**：为不同听众改写同一信息，并设计能观察语言发展的讨论。

**知识点**

1. 语言既有形式，也有意义和使用情境；会拼句子不等于会在对话中回应他人。
2. 通过复述、追问、澄清和回应证据练习倾听；讨论要有信息目标。
3. 多语言背景是教学资源；用图片、句框和同伴预演支持表达，同时保留思考难度。

**技能检查**

- [ ] 把一句课堂解释改成面向家长的说法。
- [ ] 识别语音、意义、句法或语用层面的困难。
- [ ] 给讨论设置轮次和可观察目标。

**Anchor Chart提纲**：听懂信息 → 组织表达 → 回应与澄清。

节点用于组织解释；箭头不自动代表单向因果。扩展海报时补上对应知识点、一个例子和一个边界。

**常见误区**：把英语口音不同直接判断为理解差；或只让学生齐声跟读，便认为完成口语评估。

**自编应用题**：学生能流利背诵，却在小组讨论中不回应同伴。下一步观察和教学是什么？

**参考解释**：观察其是否听懂对方、是否能接续观点；用“我同意／不同意，因为……”和追问任务练习语用，而不是只增加背诵。

**关联术语**：phonology（音系）；syntax（句法）；pragmatics（语用）；semantics（语义）。

#### 901-002 词形分析与识词

**我能完成的任务**：把复杂单词拆成有意义的部分，并验证读音和词义。

**知识点**

1. 字素与音素连接书写和发音；一个音素不一定只对应一个字母。
2. 音节帮助解码，语素帮助理解词义；同一切分不一定同时适用于两者。
3. 词典可核查读音、词源、词性和用法；语境用于确认，不应替代准确识词。

**技能检查**

- [ ] 标出前缀、词根／词基和后缀。
- [ ] 区分字母与声音、音节与语素。
- [ ] 先分析词内信息，再用上下文核验意义。

**Anchor Chart提纲**：字形与声音 → 音节与语素 → 核验意义。

节点用于组织解释；箭头不自动代表单向因果。扩展海报时补上对应知识点、一个例子和一个边界。

**常见误区**：见到不认识的词就让学生看图猜词；或把字母数当作音素数。

**自编应用题**：学生把 reusable 当作完全陌生的长词，能怎样示范分析？

**参考解释**：拆成 re-、use、-able，讨论“可以再次使用”；结合读音和句子确认。示范一次后让学生迁移到另一同构词。

**关联术语**：phoneme（音素）；grapheme（字素）；morpheme（语素）；structural analysis（构词分析）；homophone（同音异义词）。

#### 901-003 阅读流畅度

**我能完成的任务**：从准确性、速度和韵律解释朗读表现，并选择针对性练习。

**知识点**

1. 流畅朗读让识词较少占用注意力，但速度指标不能单独代表理解。
2. 韵律包括短语分组、重音和语调；应与句意配合。
3. 示范朗读、配对朗读和带反馈的重复朗读可针对具体需求安排。

**技能检查**

- [ ] 记录错词和停顿位置。
- [ ] 区分读得快与读得有意义。
- [ ] 设计带反馈的重复朗读并再次采样。

**Anchor Chart提纲**：准确性 → 适当速度 → 韵律与理解。

节点用于组织解释；箭头不自动代表单向因果。扩展海报时补上对应知识点、一个例子和一个边界。

**常见误区**：只追求每分钟词数，让学生牺牲准确性；或将独立默读当作所有流畅度问题的唯一干预。

**自编应用题**：学生读得很快，却把问句读成陈述句，也说不出段意，如何处理？

**参考解释**：检查准确性与理解，示范标点和短语的停连，再做短段重复朗读并复述意思；不要继续单纯加速。

**关联术语**：fluency（流畅度）；prosody（韵律）；automaticity（自动化）；WCPM（每分钟正确词数）。

#### 901-004 理解与文学分析

**我能完成的任务**：用文本证据区分事实提取、推断和评价。

**知识点**

1. 主旨概括一段主要讲什么；主题常表达作品对生活或人性的看法。
2. 推断连接文本线索和相关背景知识，仍需受文本限制。
3. 文本结构、体裁、作者观点和自我监控都影响阅读；策略应服务于具体理解困难。

**技能检查**

- [ ] 说清答案是明示还是推断。
- [ ] 指出支持解释的具体细节。
- [ ] 比较两种解释并排除证据较弱的一种。

**Anchor Chart提纲**：文本线索 → 推断解释 → 证据检验。

节点用于组织解释；箭头不自动代表单向因果。扩展海报时补上对应知识点、一个例子和一个边界。

**常见误区**：将个人联想直接当文本结论；或把主题缩成一个没有观点的词，如“友谊”。

**自编应用题**：人物口头说“不在乎”，却反复望向门口。怎样教学生解释？

**参考解释**：并列言语与动作证据，推断人物可能期待某人，并说明这只是受证据支持的解释；继续阅读检验。

**关联术语**：inference（推断）；theme（主题）；main idea（主旨）；metacognition（元认知）。

#### 901-005 词汇教学

**我能完成的任务**：把一个词教成可在不同语境中主动使用的概念。

**知识点**

1. 通用学术词与学科专用词需要不同支架；选词要看理解文本和表达概念的价值。
2. 同一词多次出现在不同情境，才能检验是否理解了概念边界。
3. 词义网络可连接同反义关系、词族和例子；只抄字典定义很难证明会用。

**技能检查**

- [ ] 用学生能理解的语言解释词义。
- [ ] 给出例子和非例子。
- [ ] 隔天换情境让学生口头和书面使用。

**Anchor Chart提纲**：简明释义 → 例子与非例子 → 跨情境使用。

节点用于组织解释；箭头不自动代表单向因果。扩展海报时补上对应知识点、一个例子和一个边界。

**常见误区**：把一次配对练习的正确率当成能长期主动运用；或每次只给同一个例句。

**自编应用题**：怎样教 compare，让它不仅是一个中文翻译？

**参考解释**：用两个实物比较共同点和差异，示范句框，再换到两段文本让学生自己使用 compare；用新情境检查迁移。

**关联术语**：Tier 2 vocabulary（通用学术词）；Tier 3 vocabulary（学科专用词）；semantic map（语义图）；context clue（语境线索）。

#### 901-006 探究与研究

**我能完成的任务**：从可研究的问题出发，核验来源并用自己的话整合证据。

**知识点**

1. 研究计划包括问题、资料渠道、记录方式和时间；找到很多网页不等于完成研究。
2. 一手资料与研究对象的关系比载体新旧更重要；二手资料也能有很高质量。
3. 转述要改变表达并理解意思，同时保留出处；直接引用和释义都需注明来源。

**技能检查**

- [ ] 提出能通过资料回答的问题。
- [ ] 比较来源的作者、目的和证据。
- [ ] 释义并记录出处，再写出有依据的结论。

**Anchor Chart提纲**：研究问题 → 来源核验 → 整合与标注。

节点用于组织解释；箭头不自动代表单向因果。扩展海报时补上对应知识点、一个例子和一个边界。

**常见误区**：把搜索排名、漂亮网页或域名本身当作可信度的充分证据。

**自编应用题**：两篇网页对同一历史事件说法冲突，学生该怎样继续？

**参考解释**：检查作者、日期、原始证据和写作目的，再用独立材料相互印证；说明冲突，避免只挑符合自己想法的一篇。

**关联术语**：primary source（一手资料）；secondary source（二手资料）；paraphrase（释义转述）；corroboration（相互印证）。

**配套资源**：[语言与读写：官方样题与解释](https://tx.nesinc.com/Content/StudyGuide/TX_SG_SRI_391_subtest1.htm) · [Library of Congress：一手资料分析工具](https://www.loc.gov/programs/teachers/getting-started-with-primary-sources/guides/)

#### 901-007 书写规范

**我能完成的任务**：从真实写作样本中定位规范问题，示范并检查迁移。

**知识点**

1. 规范教学要与有意义的表达相连；孤立改错不能自动迁移到写作。
2. 编辑关注约定俗成的形式，如大小写、标点和拼写。
3. 书写动作和语言组织是不同方面；应分别观察，不用字迹评判思想质量。

**技能检查**

- [ ] 分类拼写、语法、标点或书写动作的问题。
- [ ] 一次选择一个明确教学目标。
- [ ] 在新句子中检查能否独立使用。

**Anchor Chart提纲**：定位错误 → 明确示范 → 新文本迁移。

#### 902-002 数与运算

**我能完成的任务**：解释算法为什么成立，并用模型判断数的大小与运算意义。

**知识点**

1. 同一个整体中的等分才可直接比较分数；分母表示等分数，分子表示取了多少份。
2. 位值、运算性质和等值变换支撑算法；解释不能只重复口诀。
3. 整数、有理数、分数小数百分数、因数倍数与估算需要在问题中互相连接。

**技能检查**

- [ ] 在数轴与面积模型间解释分数。
- [ ] 用位值解释计算中的重组。

**常见误区**：分母越大分数一定越大；或把除法总理解为“答案必须更小”。

**自编应用题**：学生说 1/8 大于 1/4，因为 8 大于 4。如何回应？

**参考解释**：使用相同长度的整体分成八份和四份，比较单位分数，再在同一数轴上定位；强调整体必须一致。

**关联术语**：unit fraction（单位分数）；equivalent fractions（等值分数）；place value（位值）；GCF（最大公因数）；LCM（最小公倍数）；ratio（比）；percent（百分率）。

#### 902-003 模式与代数

#### 902-004 几何与测量

#### 902-005 概率与统计

**我能完成的任务**：选择恰当数据表示，解释中心、变化与可能性。

**知识点**

1. 数据回答的是具体问题；图表选择应服务于变量类型和比较目的。
2. 均值利用所有数值，中位数依赖排序后的位置；极端值影响不同。

**技能检查**

- [ ] 检查图表单位、尺度和样本来源。

**常见误区**：硬币连续正面后反面“欠着”必须出现；或只看平均数而忽略数据分布。

**自编应用题**：收入数据 20、22、23、25、210，哪种中心更能描述典型情况？

**参考解释**：中位数 23 对该极端值较稳健；均值 60 也有定义和用途，但应说明为何可能不能代表大多数观测。

**关联术语**：mean（均值）；median（中位数）；range（极差）；sample bias（样本偏差）；experimental probability（实验概率）。

#### 903-002 历史与变化

**我能完成的任务**：把事件放入时间、因果和多方经历中解释。

2. Texas 的原住民、殖民、共和国、建州及产业变化与美国和世界历史相互关联。
3. 历史解释要看时代情境、延续与变化，避免把今天的概念不加解释地投射到过去。

**技能检查**

#### 903-004 经济与选择

#### 904-007 力与运动

**我能完成的任务**：用合力解释运动变化，并正确读运动图。

3. 位置—时间图和速度—时间图不能按同一种方式读；图上的高度不是物体真实高度。

**技能检查**

**常见误区**：物体在动就一定受到朝前的非零合力；或位置—时间图越高就表示越快。

**自编应用题**：冰面上物体近似匀速滑行，能据此说没有任何力吗？

#### 904-008 物质性质与变化

**我能完成的任务**：用性质及变化证据区分物质、混合与反应。

**知识点**

1. 物质的状态变化通常不改变化学组成；化学变化形成不同物质。
2. 颜色、气泡或温度变化是线索，但单一现象并不总能证明反应。
3. 密度是质量与体积之比；溶解不等于消失，粒子仍在系统中。

**技能检查**

- [ ] 区别质量、体积和密度。
- [ ] 比较物理变化与化学变化的证据。
- [ ] 分类元素、化合物、混合物和溶液。

**Anchor Chart提纲**：性质与组成 → 变化证据 → 分类与守恒。

节点用于组织解释；箭头不自动代表单向因果。扩展海报时补上对应知识点、一个例子和一个边界。

**常见误区**：看不见的物质不存在；或任何气泡都代表化学反应。

**参考解释**：指出明暗／色彩对比使亮色成为视觉焦点，再问这种强调是否服务于表达意图；不只说好看或不好看。

**关联术语**：value（明暗）；texture（肌理）；contrast（对比）；balance（平衡）。

**配套资源**：[艺术·健康·体育：官方样题与解释](https://tx.nesinc.com/Content/StudyGuide/TX_SG_SRI_391_subtest5.htm) · [TEKS 艺术 Chapter 117](https://tea.texas.gov/laws-and-rules/texas-administrative-code/19-tac-chapter-117)

#### 905-002 音乐

**我能完成的任务**：在听、唱、奏、创中区分音乐要素并解释表达选择。

**知识点**

1. 节拍是持续的脉动，节奏是时值组织；速度决定脉动快慢。
2. 音高、音色、力度和曲式是不同维度，需通过听觉及实践连接术语。
3. 音乐与社会文化情境相关；介绍传统时应保留其用途和背景，而非仅当装饰。

**技能检查**

- [ ] 区分节拍、节奏、速度和力度。
- [ ] 听辨或表现简单形式与音色差异。
- [ ] 按可观察标准评价演唱演奏。

**Anchor Chart提纲**：听辨要素 → 表现与创作 → 文化与评价。

节点用于组织解释；箭头不自动代表单向因果。扩展海报时补上对应知识点、一个例子和一个边界。

**常见误区**：更响就是更高音或更快；或让学生只背符号而没有声音经验。

**自编应用题**：同一旋律先轻后响但拍速不变，改变的是 tempo 还是 dynamics？

**参考解释**：改变的是 dynamics（力度）；tempo（速度）不变。再通过实际演奏分别改变速度和力度来比较。

**关联术语**：tempo（速度）；dynamics（力度）；timbre（音色）；rhythm（节奏）；meter（节拍组织）。

**配套资源**：[艺术·健康·体育：官方样题与解释](https://tx.nesinc.com/Content/StudyGuide/TX_SG_SRI_391_subtest5.htm) · [Smithsonian Folkways：音乐学习与教案](https://folkways.si.edu/learn)

#### 905-003 健康教育

**我能完成的任务**：把健康知识转化为信息评价、决策、沟通和求助技能。

**知识点**

1. 健康包括身体、心理、情绪和社会关系等方面，不能只教身体器官。
2. 营养、活动、预防、安全及物质使用风险等需联系日常选择。
3. 健康教育应让学生练习决策和求助，不能把知识问答正确当作行为技能已经掌握。

**技能检查**

- [ ] 识别健康信息的来源与目的。
- [ ] 比较选择后果并说明理由。
- [ ] 为适龄情境练习拒绝、沟通或寻求帮助。

**Anchor Chart提纲**：可信信息 → 选择与后果 → 沟通及求助。

节点用于组织解释；箭头不自动代表单向因果。扩展海报时补上对应知识点、一个例子和一个边界。

**常见误区**：让学生披露个人健康隐私来换取课堂参与；或把健康状态当作个人品德评价。

**自编应用题**：广告称某饮料能立刻提高学习成绩，学生应怎样判断？

**参考解释**：检查发布者、证据、利益目的和是否夸大因果，再查可靠信息并作决定；不以广告流行程度证明有效。

**关联术语**：health literacy（健康素养）；risk factor（风险因素）；refusal skill（拒绝技能）。

**配套资源**：[艺术·健康·体育：官方样题与解释](https://tx.nesinc.com/Content/StudyGuide/TX_SG_SRI_391_subtest5.htm) · [CDC：营养与身体活动的学校策略](https://www.cdc.gov/assessing-improving-school-health/nutrition-pa/index.html) · [TEKS 现行课程标准总入口](https://tea.texas.gov/curriculum-and-instruction/texas-essential-knowledge-and-skills-teks)

#### 905-004 体育与动作发展

**我能完成的任务**：设计安全、包容且可观察进步的动作学习。

**知识点**

1. 体育教学包含动作技能、体适能、合作和长期参与，不只是比赛结果。
2. 平衡、协调与技能熟练需要适龄分解、示范和大量有效练习。
3. 评价可关注动作质量与个人进步；通过器材和任务调整使不同学生都能参与。

**技能检查**

- [ ] 区分位移、非位移和操控动作。
- [ ] 根据动作线索提供具体反馈。
- [ ] 调整距离、器材或规则以增加有效练习。

**Anchor Chart提纲**：动作目标 → 安全练习 → 反馈与进步。

节点用于组织解释；箭头不自动代表单向因果。扩展海报时补上对应知识点、一个例子和一个边界。

**常见误区**：把出汗多少当成掌握动作的证据；或只让技能好的学生获得比赛和练习机会。

**自编应用题**：部分学生接不到小球，怎样调整而不取消目标？

**参考解释**：先使用较大或较慢的球、缩短距离并教授看球和手位，再逐步增加难度；保持接球目标并记录动作进步。

**关联术语**：locomotor skill（位移动作）；nonlocomotor skill（非位移动作）；manipulative skill（操控动作）；FITT（运动计划要素）。

**配套资源**：[艺术·健康·体育：官方样题与解释](https://tx.nesinc.com/Content/StudyGuide/TX_SG_SRI_391_subtest5.htm) · [CDC：学校与身体活动](https://www.cdc.gov/physical-activity-education/about/index.html) · [TEKS 现行课程标准总入口](https://tea.texas.gov/curriculum-and-instruction/texas-essential-knowledge-and-skills-teks)

#### 905-005 戏剧

**我能完成的任务**：通过角色、动作和冲突进行创作，并用证据评价表现。

**知识点**

1. 戏剧可通过即兴、哑剧、剧本和合作创作发展表达，不要求先有精致舞台。
2. 角色动机与冲突推动行动，表演选择应服务于情境。
3. 舞台方向常从演员视角定义；观众礼仪、制作分工和安全也属于学习内容。

**技能检查**

- [ ] 识别角色、场景、冲突与行动。
- [ ] 用声音、表情和身体表达角色。
- [ ] 按共同标准反馈并修订表演。

**Anchor Chart提纲**：情境与角色 → 动作与冲突 → 表演及反馈。

节点用于组织解释；箭头不自动代表单向因果。扩展海报时补上对应知识点、一个例子和一个边界。

**常见误区**：把舞台左直接按观众左判断；或只按是否背熟台词评价戏剧学习。

**自编应用题**：角色一边说“欢迎”一边后退，表演可以传达什么，如何讨论？

**参考解释**：可能表达犹豫或害怕，但需结合剧情和动作证据；让演员说明意图，再试不同动作比较效果，不预设唯一情绪。

**关联术语**：improvisation（即兴表演）；pantomime（哑剧）；conflict（冲突）；stage direction（舞台指示）。

**配套资源**：[艺术·健康·体育：官方样题与解释](https://tx.nesinc.com/Content/StudyGuide/TX_SG_SRI_391_subtest5.htm) · [TEKS 艺术 Chapter 117](https://tea.texas.gov/laws-and-rules/texas-administrative-code/19-tac-chapter-117)

## 9. 开屏学习看板该显示什么

建议只展示少量行动入口，详细内容留在关联看板中。以下未改动开屏设置。

1. **今天理解一条考纲**：编号及用自己的话解释的目标。
2. **今天完成一个技能**：对应三条可观察标准。
3. **今天重画一张图**：先回忆，再显示图解。
4. **今天解决一个误区**：先回答，再看解释。
5. **今天复习几个词**：从当前单元选词并放回情境使用。
6. **今天使用一个资源**：附具体任务，避免只收藏链接。
7. **下次复测**：记录待复测单元，不预填考试日期。
