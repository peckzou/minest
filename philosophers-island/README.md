## 一、 六大思想街区与 Top 20 哲学家住宅

   - **#15 黑格尔（Hegel）**：柏林三层辩证螺旋塔与塔顶密涅瓦猫头鹰
   - **#16 马克思（Marx）**：大英阅览席与外墙实时旋转的“经济基础与上层建筑”双层黄铜蒸汽齿轮坊
7. **第六街区（北峰悬崖与黑森林）· 存在主义与语言分析高地**
   - **#17 叔本华与克尔凯郭尔（Schopenhauer & Kierkegaard）**：生命意志钟摆室与信仰之跃悬崖亭
   - **#18 尼采（Nietzsche）**：全岛最高峰（y=51）锡尔斯玛丽亚高山木屋、查拉图斯特拉金字塔巨石与永恒轮回沙漏

   - **#20 海德格尔与萨特（Heidegger & Sartre）**：黑森林林中空地木屋“上手之锤”与左岸自由选择咖啡座

## 三、 面对面对谈 · 思想星图

走近任意哲学家按 **`E`**，或在罗盘里点 **`💬 对话`**，进入电影式对谈：镜头推近、上下遮幅收拢，哲学家的话以大字幕逐字浮现。

- **思想星图**：十二颗星环绕在哲学家身边——人生、真理、苦难、今日 AI、论敌与知己、馆藏名画，以及生平、思想模型、著作、三个核心概念。点亮一颗，他就讲这一段；左上角头像外圈显示点亮进度。
- **字幕**：一次一小段，点击画面 / `Space` / `Enter` 继续；讲完后他会反问你一句，可以 **`⚔ 反驳`** 或 **`↧ 再深一层`**。
- **思想模型 / 生平 / 著作**：字幕上方出现步骤轨、年表或书脊，可逐步推进，也可点任一节点跳转。
- **直接提问**：底部输入行（按 `/` 聚焦）或点快捷问题；问到哪个话题，对应的星会被点亮。
- **⋯ 更多**：对话回顾、保存对话、重新开始、同一问题问诸家（观点对比）、我的收藏、百科与馆藏、思想实验。
- 收藏存在浏览器 `localStorage`（`minest.philosophers.saved.v1`）。回应由本地脚本按各家立场生成，未连接 AI 服务。

## 五、 全息操作台与交互思维模型

每座展馆里（哲学家右后方）都有一台全息操作台，思维工坊（阿波罗神庙）里有一台总台。走近按 **`E`** 启动；也可以从对谈的「⋯ → 🔷 全息操作台」或罗盘进入。

- **知识星图**：本馆哲学家的核心概念、思想模型步骤、生平、著作、观点和名言，以星图呈现，可拖转、缩放、点开。
- **交互模型**：左上角列出本馆的模型，星图里也有对应的模型星（点开 →「▶ 启动交互模型」）。体验过的会打勾。`Esc` 先退回操作台，再按一次回到小岛。
- **思维工坊总台**：全部 136 个模型，按学科分组；也可「按目录浏览」。
- 模型与展馆的对应关系在 `pi-world/models.js` 的 `ROOMS` 里，改这一处即可调整。

目录：`philosophy/models/`（136 个模型页）、`holo-lab/` `holo-lab-2/` `tools/` `type3d/`（全息操作台）。进度存在 `localStorage`（`minest.philosophers.models.v1`、`minest.philosophers.holo.*`）。

### 全息 3D 模型与 Obsidian 模式

- **全息 3D 模型**：二维微交互可以升级成投影在操作台上的 3D 全息版本。第一个是休谟馆的「因果关系」（`holo-lab-2/sim-hume.js`）：四关、步骤和原文与二维版一致，可以绕着看；按住画面或空格推进，拖动 B 球 / 探针 / 「心灵」/ 三块「理由」。工具条里可切关、重置、打开二维原版。
- **怎么再升级一个**：用 `HL.sims.define(key, {...})` 写一个 `sim-<key>.js`（套件见 `holo-lab-2/sims.js`），在 `holo-lab-2/index.html` 里引入，再到 `pi-world/models.js` 给对应模型加 `"holo": "<key>"`。
- **Obsidian（第 6 个模式）**：模式栏最右。全岛的知识库以 Obsidian 式图谱投影出来 —— 20 位哲学家、核心概念、思想模型、交互模型共 125 篇笔记，由 `[[双向链接]]` 相连。单击高亮相邻笔记，双击在右侧打开（含反向链接，可「前往展馆」或「启动交互模型」）。图谱本体是 `living-knowledge/graph/`。

### 全部模型的全息投影 · Obsidian 的六种视图

- **全息投影（全部 136 个模型）**：任何模型启动后都直接投影在操作台上（`holo-lab-2/sim-projector.js`）。模型在后台实时运行，画面成为悬浮在投影区里的弧形光幕；在光幕上拖动、按住、点击与原版一致，拖动光幕外的空白处转动视角。模型自己的分关和按钮变成底部工具条；右侧面板显示核心问题、**下一步试试**、逐条点亮的原文和适用边界。休谟「因果关系」另有重新搭建的 3D 版。工具条里可随时打开「2D 原版」。
- **模型目录改为 `philosophy/models/`**：模型总目录里的链接写的是这个绝对路径，放在别处时从目录点进任何模型都会 404。
- **Obsidian 六种视图**：图谱 2D / 星系（3D 力导向）/ 星环（每位哲学家是一颗恒星，概念与模型绕着转）/ 螺旋（按年代沿时间螺旋上升）/ 地层（人物、概念、思想模型、交互模型四层）/ 知识球。3D 视图里轻点一颗星：相连的笔记亮起、光点沿链接流动，并在右侧打开笔记。

### 旅程：登岛 → 对谈 → 散步 → 圆桌会议

- **登岛过场**：第一次打开时，探索者乘船到南岸木栈桥上岸（约 16 秒，`Esc`/空格跳过），随后以第三人称接管。`V` 切换第一 / 第三人称。地址加 `?nointro=1` 可跳过过场。
- **旅程面板**（左上）：六步引导——走向中央广场、拜访一位哲学家、圆桌对谈、边走边谈、召开圆桌会议、自由探索；带方向与距离提示、「⏩ 带我去」「跳过引导」「↺ 重走旅程」。进度存在浏览器本地。
- **转场**：进入圆桌、散步、会议和结束时有黑场淡入淡出和章节字幕。
- **圆桌会议**：按 `C`（或罗盘 / 对谈「⋯」菜单）出题并请 2–5 位思想者到广场东南的大圆桌围坐。他们轮流陈述，可「互相回应」「各出一个点子」「主持人小结」、点名、追问，并把发言「记到白板」（白板存在本地，可复制）。发言由本地脚本按各家学说拼出，不是 AI。
- 代码：`app.js`（`startArrival` / `updateCine`、`sceneTalk` 与 `transition`、`S.tp`、`STEPS` / `setStep`、`startCouncil`）、`portals.js`（`openCouncilSetup` 等）、`world.js`（登岛栈桥）。

### 任务板与笔记本

- **任务板**（左上面板「📋 任务板」或 `B`）：写下今天想了解什么（如"辩证法是什么"），岛上推荐最该去找的思想者（最多三位，附理由和馆里可玩的全息模型）。可选「先自己去逛」「看全息屏」「圆桌对谈」「散步交谈」或「只接任务」。接下的学习任务以三项清单显示在面板里，带方向和距离。
- **笔记本**（「📓 笔记本」或 `N`）：每次对谈、散步、圆桌会议结束后自动记一条（问题、对象、方式、看过的模型、完整问答）。数据在 `localStorage` 的 `minest.philosophers.notebook.v1`，可导出 JSON / Markdown。
- 推荐是本地关键词匹配（`portals.js` 的 `recommend`：各馆的核心概念、模型名、思想模型步骤、立场，加一张日常话题表 `REC_THEMES`），不是 AI。

### 读法 · 第三版（`library/read.html`，十个页签）

- **内部**：走近按 `E`（或罗盘、词根馆页顶的按钮）打开 `rootmap/sphere.html`：208 块小屏幕贴成一个球，每块播放一张词根动图；可拖动旋转、滚轮缩放、按词根高亮、点一块放大并朗读；「走进球内」切到在球心环视的视角。只有朝向你的屏幕在加载动图。
- **自己的画面上 Sphere**：在岛上按 `X` 选一个本地的图片、GIF 或视频，它会铺满 Sphere 的外壳（视频静音循环；GIF 在支持 ImageDecoder 的浏览器里逐帧播放）；`Shift+X` 恢复默认轮播。文件只在本次打开期间有效，不上传、不保存。
- **球内巨幕导入素材**（`rootmap/sphere.html`）：顶部「📂 导入素材」可一次选多张图片、GIF 或视频：多个素材轮流铺在各块屏上，单个素材默认「一幅铺满」整个球幕（可用「▣ 一幅铺满」切换）；「↺ 恢复词根」回到默认。「⛶ 全屏」或 `F` 进全屏；「👁 隐藏界面」或 `H` 隐藏所有按钮、筛选条和座椅，`H` / `Esc` 恢复。素材只在本次有效，不上传。
- **时光岛的场地**：岛上不再随机种树（`pi-world/annex.js` 去掉了这座岛的树丛）；`pi-world/app.js` 的 `buildTimeIsleGrounds()` 按各建筑的风格铺了外围：图书馆前是浅色石材前庭、绿篱、灯柱和花瓮；Sphere 脚下是深色圆形广场和三圈彩色光环、一圈发光矮柱；词根馆是紫色铺地和光带镶边；光锥周围一圈石环，几条小路把它们连起来。
