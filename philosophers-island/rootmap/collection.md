# 思维模型 GIF 集

补《交互思维模型》（34 个可玩工具）和《哲学家思想动画讲解》（25 项）留下的缺口：**一个思想，一张独立动图**。只收真正验证过的 GIF。

核实日期：2026-11-24。核实标准（每张都做到）：直链能打开、响应是 `image/gif`、用 ffprobe 数过帧数（多帧才算动图）、抽帧看过画面内容，确认讲的就是这个思想，不收标题党和无关图。

> 关于 Wikimedia Commons 的说明：2026-11-24 当天 `upload.wikimedia.org`（原图站）从这台机器访问持续返回 429 限流。Commons 的 5 张图改用 `thumb.wikimedia.org` 的同文件缩略图版核实——缩略图保留了完整动画（帧数见下），链接能直接打开。下面每条同时给出原图直链和已核实的缩略图直链；原图链接本身是 Commons 的标准地址，只是当天从这里打不开，换个网络一般能打开。

## 四、核实方法（可复现）

```bash
# 1. 看响应头是不是 image/gif
curl -s -I <直链>  # Content-Type: image/gif
# 2. 下载后数帧（多帧 = 真动图）
ffprobe -v error -count_frames -select_streams v:0 \
  -show_entries stream=nb_read_frames,width,height -of default=noprint_wrappers=1 <文件.gif>
# 3. 抽中间帧看画面，确认内容
ffmpeg -v error -i <文件.gif> -vf "select=eq(n\,<中间帧>)" -vframes 1 frame.png
```

Wikimedia Commons 原图站当天 429 限流时，改用同文件的 `thumb.wikimedia.org` 缩略图版核实（缩略图保留完整动画，帧数以缩略图为准，如忒修斯之船 252 帧）。
