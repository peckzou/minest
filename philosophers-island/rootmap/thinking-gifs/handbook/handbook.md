# 思维模型手册 · 火柴人 GIF 集（100 张）

《思维模型手册》100 个模型（think.knowledgefxg.com，八大类别）全部做成火柴人动画 GIF。
和《思维模型 GIF 集》里那 11 个思想实验的火柴人版是同一套做法、同一风格，但场景全部新写。

- **风格**：墨 `#141414`、白纸底、一个奶油黄/强调色、大量留白；火柴人是主角，每图只放几个词，中文为主、配英文模型名。
- **规格**：每张 60 帧、480×270、6 秒、10 fps。
- **做法**：每个场景一份 `.js`（`templates/scene.js` 起手），按 stick-scene 技能流程走完 contact sheet 看图 + `motion.mjs` 查到 "motion is clean" 才出 GIF；每张都抽开头/中间/结尾 3 帧看过画面，确认讲的就是这个模型、无裁切遮挡、首尾回到 idle。
- **已知小问题（全集通用）**：Google Fonts 在这台机器上加载失败，文字用 fallback 字体渲染（中文不受影响）；为首尾衔接做的循环复位（淡出、走回原位、东西缩回）不是剧情本身的一部分。各张的具体小毛病写在下面每行的“备注”栏和各类别的“已知小问题”里，没藏。

## 复现

```bash
# 出 contact sheet（看图检查）
NODE_PATH=/tmp/stick-playwright/node_modules node ~/workspace/custom-skills/stick-scene/scripts/frames.mjs \
  --scene <id> --src <id>.js \
  --frames "idle:0,idle:2.5,s:0.8,s:1.6,s:2.4,s:3.2,s:4.0,s:4.8,s:5.6" --fw 400 --out /tmp/<id>-sheet.png
# 查动作
NODE_PATH=/tmp/stick-playwright/node_modules node ~/workspace/custom-skills/stick-scene/scripts/motion.mjs \
  --scene <id> --src <id>.js
# 出 GIF（60 帧、480×270、10fps；GIF 落在 frames-<id> 的上一级）
NODE_PATH=/tmp/stick-playwright/node_modules node ../stick-figure/render-gif.mjs \
  --scene <id> --src <id>.js --dur 6 --fps 10 --fw 480 --fh 270 --out frames-<id>
```

`render-gif.mjs`（在 `../stick-figure/`）是自写的拼 GIF 脚本：用 playwright 沿 `s:0.0–5.9` 每 0.1 秒取一帧，再用 ffmpeg 拼成循环 GIF。Playwright 装在 `/tmp/stick-playwright`（`playwright@1.56.1` + Chromium Headless Shell）。
