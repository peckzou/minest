# 唐顿庄园 · 海克利尔城堡体素世界（Downton Abbey / Highclere Castle）

Minest "My World" 的独立场景，打开 `downton.html` 即可。复用新天鹅堡的体素引擎（`da-world/`，命名空间 `DA`），不改动其他世界，也不依赖任何外部资源或付费 API（只用本地 `vendor/three.min.js`）。

## 内容

**室外**
- 主楼：Bath 石外墙，四角塔楼和中央方塔（顶上挂英国国旗），雉堞女儿墙，两扇一组的竖棂窗。
- 北面入口门廊、台阶、平台栏杆。
- 车道、喷泉、南草坪、围墙花园（砖墙和黄杨绿篱花坛）。
- 远景：Heaven's Gate、Jackdaws Castle、Milford Lake、麦田、羊群（18 只），还有一圈白垩丘陵。

**室内（底层）**
- 中央 Saloon，带二层回廊。
- 入口大厅、东侧大楼梯（含平台）。
- 西侧双间图书室：深色木书柜、壁炉、阅读桌椅。
- 餐厅：长餐桌、烛台、油画。
- 客厅（Drawing Room）、音乐室（有钢琴）、书房。

**室内（楼上）**
- 北、南、西三间卧室，配床、床头柜和蜡烛、床尾长榻、壁炉、扶手椅、写字台。

**全局**
- 吊灯、蜡烛、油画都是代码绘制的风格化图案，题材有肖像、骑马像、风景、狩猎。
- 昼夜滑块。
- 进入室内后自动切换室内光照，并显示房间名称。

## 操作
| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 行走 |
| 鼠标 / 触屏拖动 | 视角 |
| 空格 | 跳；飞行时上升；双击切换飞行 |
| C | 下降（飞行时 Shift 也可） |
| Shift / Ctrl | 跑 |
| F | 步行 / 飞行切换 |
| E | 开关门（双扇门两扇一起开）、坐下 / 起身 |
| T / Y | 切换时间 / 自动巡游 |
| H | 隐藏帮助 |

手机上用屏幕摇杆和按钮操作。

## 真实与估算
- 海克利尔城堡由 Charles Barry 设计，约 1839–1842 年改建，外观为 Jacobethan / 意大利文艺复兴混合风格。
- 本场景的平面是简化版：房间位置参照真实布局（Saloon 在中央，图书室在西侧，餐厅、书房、大楼梯、客厅、音乐室分布在周围）。
- 尺寸都是估算：主楼约 56×50 格，中央塔顶 y=74。
- 家具、油画和远景都是风格化表达，不是测绘复原。

## 测试（沙箱内，软件渲染）
- `tools/bfs.js`：从出生点出发的可达性检查，覆盖全部检查点（含楼上卧室、Heaven's Gate、Jackdaws Castle），共 61582 格，不可达 0。
- `tests/views.pw.js`：13 个视角截图。加载 1.8 s，无报错。
  - 绘制调用 113（起始）→ 250（巡游后）。
  - 三角形 107k → 233k。
- `tests/interaction.pw.js`：交互流程全部通过。
  - 沿车道走到正门，开门进屋，经楼梯平台上到二楼。
  - 打开客厅门进入，坐下再起身。
  - 从南门走到室外，室内光照随之切换。
  - 夜间模式正常。
  - 内存堆约 46 MB。
- 沙箱里的 20 fps 是软件渲染造成的，不代表真实设备。
