# Minest · 哲学交互模型（13 个，实时交互版 V1.0）

Boost delivered these on 2026-11-22 (`Minest_哲学交互模型.zip` and `Minest 交付文档.docx`). The files are kept as delivered. Each page is a single self-contained HTML file using Canvas 2D: no network requests and no storage.

- The quotations come from public-domain English translations (236 quotes, checked word for word by the developer). The Chinese text is the developer's own compilation, not a published translation.
- `index.html` is the catalogue, and each model's "← 总目录" links back to it.
- In Minest they open from the Cognitive Toolkit → 思维实验室 card (`tools/toolkit/phil-models.js`).
- Known issues and untested items are listed in the delivery document: touch feel, iPhone portrait layout, and frame rate.
