# Minest · 哲学交互模型（46 个，实时交互版）

Boost delivered these on 2026-11-22 (`Minest_哲学交互模型.zip`: 13 models, then `Minest_哲学交互模型 (2).zip`: 33 more). The files are kept as delivered. Each page is a single self-contained HTML file using Canvas 2D, with no network requests. Seven of the newer models keep their own progress in localStorage, under `minest_<model>_*` keys.

- The quotations come from public-domain English translations (236 quotes, checked word for word by the developer). The Chinese text is the developer's own compilation, not a published translation.
- `index.html` is the catalogue, and each model's "← 总目录" links back to it.
- In Minest they open from the Cognitive Toolkit → 思维实验室 card (`tools/toolkit/phil-models.js`).
- The delivery document covers only the first 13. For the other 33, the sources in the registry are each model's primary work. Known issues and untested items are listed in the delivery document: touch feel, iPhone portrait layout, and frame rate.
