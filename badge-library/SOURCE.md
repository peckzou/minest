# Minest Badge Library

This directory is the production build of the standalone badge repository.

- Source: https://github.com/peckzou/badge
- Source commit: `751f06f15781f71d2b7b5de9ce436b8105092637`
- Built with: `vite build --base=./`
- Imported: 2026-09-27

The relative asset base is intentional. It allows the complete Three.js badge
catalog to run from Minest's static server, GitHub Pages, and an iOS WKWebView
without relying on an AI Studio authentication session.
