# Clun 室内 2.0

在 [Clun 1.0](../clun/) 上面加一层：1.0 的脚本（`../clun/js/*.js`）和页面一个字不改，1.0 还在原来的地址。
这一页用 `<base href="../clun/">` 原样加载 1.0 的全部脚本，再加三个自己的。

## 打开

```bash
python3 -m http.server 3005        # 在仓库根目录
```

`http://localhost:3005/spatial-home/clun-2/`，点「🚶 走进去」（或地址加 `?inside=1` 直接进屋）。1.0 的地址参数都还能用。
合并到 main 后的线上地址：`https://minest-app.vercel.app/spatial-home/clun-2/`。

## 门

- 房门默认都开着，**书房**和**阳光房**（屋后左上角伸进后院的那间）两处默认关着。开着的门是真的画成开着的，不只是状态。
- 客厅通阳光房在 1.0 里只是一个带门套的洞口；2.0 在洞口里装了一对白框玻璃门，朝阳光房开，两扇一起开关。
- 开门、关门和 1.0 一样：走近点「🚪 开门 / 关门」，或者直接点门。书房门上有一块小铜牌。
- 门开着以后会挡路的几件 1.0 家具挪开了（只在 2.0 里挪，1.0 不动）：餐厅门口的格子柜和红脚凳、儿童房门后的扶手椅和沙发床、
  起居室通厨房洞口前的扶手椅；厨房西墙的通顶高柜在 1.0 里把这个洞口挡死了，2.0 让它停在洞口前，现在能从起居室走进厨房。

## 室内

- 每个房间：墙纸或墙漆、踢脚线、护墙板 / 挂镜线、顶角线（遇到门洞、窗洞自动断开）；卫生间和浴室是瓷砖墙裙。
- 书房重做：橡木护墙板、墨绿暗花墙纸、红丝绒窗帘、老地图、书梯、边几和酒瓶、绿罩吊灯。
- 各房间添了家具和小件：衣柜、窗帘 / 卷帘、绿植、书、餐桌和岛台上的摆设、浴室洁具和毛巾、儿童房的玩具和地毯、更多的画。
- 客厅壁炉的火会跳，灯有光晕；走进一个房间，屏幕上显示房间名。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 页面：1.0 的脚本 + 下面三个 |
| `v2-kit.js` | 贴图和材质、摆家具的小工具、房间表（`V2.rooms`、`V2.roomAt`）、沿房间墙面贴一圈的 `finish` |
| `v2-rooms.js` | 包住 1.0 的 `Clun.buildFurnishings`：挪家具、各房间的装修和家具、门的默认状态（`V2.CLOSED`）、阳光房玻璃门 |
| `v2-live.js` | 房间名、炉火、灯的光晕 |

## 测试

```bash
node tests/clun-2/clun2.test.cjs      # → clun-2: ok
```

不开浏览器，用 three.js 把整栋房子建出来，检查：1.0 的脚本按原顺序原样加载；15 扇门里只有书房和阳光房的关着，其余画成开着；
阳光房的两扇一起开关、朝阳光房开；每扇开着的门扇不碰家具、门洞里没有东西；起居室到厨房走得通；挪过的椅子「坐下」的位置跟着挪。
