# Admont assets (drop-in)

Public-domain + CC0 ONLY. No CC BY-SA, no paid API, no attribution page required.

## textures/

Real CC0 textures to override the procedural placeholders in `admont-world/textures.js`.
Use these exact filenames (named in that file's top comment):

- `marble_floor_diff.jpg`   - marble floor      (e.g. Poly Haven "marble_01", CC0)
- `white_plaster_diff.jpg`  - white stucco wall (e.g. Poly Haven "plaster_wall", CC0)
- `gold_leaf_diff.jpg`      - gilt / gold trim  (e.g. Poly Haven "gold_metal", CC0)
- `carved_wood_diff.jpg`    - bookcase carcase  (e.g. Poly Haven "wood_cabinet", CC0)
- `leather_books_diff.jpg`  - book spines       (e.g. Poly Haven "book_pattern", CC0)

## frescoes/ (FEAT-002)

Public-domain photographs of the seven Bartolomeo Altomonte ceiling frescoes
(the artist died in 1783, so the works are public domain). Place them here as
`fresco_1.jpg` .. `fresco_7.jpg` and the scene will map them onto the ceiling panels.
