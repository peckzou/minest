# 拜伯里 · Bibury（阿灵顿排屋）体素世界

Minest "My World" 的独立场景，打开 `bibury.html` 即可。复用唐顿庄园的体素引擎（`bb-world/`，命名空间 `BB`），不改动其他世界，也不依赖外部资源或付费 API，只用本地的 `vendor/three.min.js`。

## 内容
- **阿灵顿排屋（Arlington Row）**：十间相连的科茨沃尔德石头小屋，沿小路逐级上坡。
  - 外观：陡峭的石板屋顶，每间一个山墙式老虎窗，带滴水线的竖棂窗，彩色木门，共用的烟囱，门前种灌木和花，墙上爬着玫瑰、紫藤、常春藤。
  - 室内（每一间都能进）：石板地面，橡木梁天花板，石砌壁炉和炉火，一段陡楼梯通到屋顶下的卧室。
  - 四种布置轮换：织工小屋（织布机）、厨房（餐具柜、餐桌）、起居室（沙发、地毯、书架）、普通小屋。9 号标为国民信托的小屋。
- **小路、溪流、拉克岛**：小路旁是草坡和一条引水溪，对面是拉克岛水草甸，长着芦苇、草和野花。一座木板桥通到观鸟平台，平台上有长椅。
- **科恩河**：清澈的浅河，有天鹅、绿头鸭和垂柳，河上有一座三拱石桥。
- **阿灵顿磨坊**：三层石砌磨坊，里面有两对石磨、面粉袋和长椅。
- **拜伯里鳟鱼养殖场**：四个石砌边的鱼池，池里有游动的鳟鱼，另有一间木屋和围栏。
- **天鹅酒店**：外墙爬满常春藤的驿站旅馆，有老虎窗和店招。室内是酒吧（吧台、酒架、高凳、壁炉）和餐厅。
- **圣玛丽教堂**：西塔带雉堞和尖塔，塔上挂圣乔治旗。中殿有长椅和彩色玻璃，圣坛有栏杆和祭坛，南门廊有石凳。墓园有墓碑、紫杉和干砌石墙。
- **坡上小屋和路边小屋**：六间独立小屋，室内同样可以进。
- **周围**：干砌石墙围出的油菜田、大麦田和牧场，有科茨沃尔德狮子羊。远处是低缓的科茨沃尔德丘陵。
- **全局**：昼夜循环，晚上窗户亮灯，烟囱冒烟，天上有寒鸦。

## 技术要点
- 屋顶：体素做成阶梯状，负责碰撞和室内天花板。上面另外盖一层平滑的石板斜面网格，坡度约 51°，带屋脊、檐口和山墙封边。阶梯与斜面之间的三角缝用山墙网格补上，贴图与墙体体素对齐。全村所有屋顶合并成一次绘制调用。
- 常春藤、芦苇和野花是透明贴图平面，围栏、天鹅和鳟鱼是小网格，每一类合并成一个网格。
- 每个建筑模块自带检查点，`tools/bfs.js` 从出生点检查是否都能走到，包括每间小屋的楼上。

## 真实与估算
- 阿灵顿排屋约建于 1380 年，原是修道院的羊毛仓库，17 世纪改成织工小屋，现由英国国民信托管理。
- 磨坊建于 17 世纪；鳟鱼养殖场建于 1902 年；圣玛丽教堂起源于撒克逊时期。
- 布局是简化版：排屋、小路、溪流、拉克岛、河、桥、酒店、教堂的相对位置大致参照实际，距离和尺寸都是估算。排屋做成整齐的十间，真实的排屋宽窄和高低更不规则。
- 室内布置、画作和店招都是风格化表达，不是复原。

## 测试（沙箱内，软件渲染）
- `tools/bfs.js`：46 个检查点全部可达，不可达 0。
- `tests/views.pw.js`：17 个视角截图，加载约 1.6 s，无报错。绘制调用 58–116，三角形 17–25 万。
- `tests/interaction.pw.js`：交互流程全部通过。
  - 沿小路走，进 8 号小屋，楼梯上到卧室，显示"阁楼卧室"。
  - 坐下再起身，出门回到小路，室内光照从 1.0 降到 0.25。
  - 在天鹅酒店开门进餐厅，在教堂开南门进中殿并坐进长椅。
  - 夜间亮灯，内存堆约 59 MB。
- 沙箱里的 20 fps 是软件渲染造成的，不代表真实设备。

## 局限
- 没有在真机或 GPU 上测过。
- 酒店和磨坊的楼上不能进。
- 芦苇不随风摆动，天鹅和鸭子是静止的。
- 中文字体在沙箱截图里显示为方框，浏览器中正常。
