Cloud Workspace sync fix — 2026-10-28
Branch: codex/cloud-workspace-sync (based on Duo aquarium dd3c821)

Confirmed production defect at https://minest-app.vercel.app/iphone:
customWorkspaces only wrote minest.customWorkspaces.v1 in localStorage. Empty
folders never changed boards, entered no payload and triggered no cloud save.

Implementation:
- Keep the original names key. Add versioned name/deletion records to a sidecar
  and the existing focusboard/data document as workspaceGroups. No separate
  Card system, new Firestore path, security-rule or environment changes.
- Recover legacy local names. Merge concurrent additions and retain tombstones.
  Confirmed server snapshots acknowledge group records; cache snapshots do not.
- Notify the mounted picker and cloud save effect immediately on group changes.
- Replace the 300ms remote edit suppression window with exact array identity.
- Serialize automatic saves; acknowledge only the dirty revision captured before
  compression. Edits during compression/upload remain pending. Sync Now awaits
  the current write and server snapshot and distinguishes queued changes.
- Wait for a server snapshot before enabling automatic uploads, preserving offline
  edits until merge. Report local-storage quota failures when saving a group.
