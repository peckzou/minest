WHAT WAS ADDED
- Watch rings page: top-right playback icon; also a playback page in the Crown
  page sequence. Existing ring goals, focus, lists and badges remain available.
- Shows list, current card, position, playing/paused state. Tap card text for a
  larger reading sheet; the compact preview keeps Next within reach.
- Next and explicit Pause/Resume operate the phone's existing CarFlashStore.
  Phone web panel, Live Activity and CarPlay widget use that same store.
- Existing normal auto-play supports variable per-card durations and looping.
  GPT Study uses the persisted queue and existing progress events, never wraps.
- watchOS 11+: Next is the official handGestureShortcut(.primaryAction).
  On supported hardware with double tap enabled, open this playback page, raise
  the wrist, then double tap thumb and index finger. This is not a screen double
  tap or an always-on/background gesture. Older watches retain touch buttons.
- Cached timeline, refresh, reconnection refresh, bounded payloads and timeouts.
- Commands require a live request/reply connection. They carry a playlist session
  ID, unique command ID and short freshness window. No delayed/offline Next queue.
  Retransmitting the same ID does not advance twice; rejected commands do not
  alter playback. Pause/Resume is a desired state, not a blind toggle.

IMPLEMENTATION

WatchPlaybackProtocol.swift copies identical (the test runner checks both).
Application context merges existing board/ring fields; if playback would exceed
its message budget, it is omitted there and remains available via live requests.
No Firebase, AI, cloud API, production environment or deployment changes.

BUILD / INSTALL
Open ios/Minest/Minest.xcodeproj in this worktree, not the original checkout.
Use the existing signing team. Run scheme Minest on the paired iPhone and
MinestWatch on its Apple Watch. Both sides must be updated for this protocol.
Start a card playlist with the existing iPhone Duo card-playback / CarPlay panel.
Open Watch's playback icon, then use Next, Pause/Resume or system double tap.
Connection unavailable: controls disable; the watch labels its cached progress.
No new API key, server or environment variable is required.
