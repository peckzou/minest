# Focusboard Cloud (Minest)

3D Cover Flow 视效管理看板 & 主动提取闪卡系统

## 📱 核心版本入口

- **智能自适应入口**：`index.html`（电脑自动打开桌面版，手机自动打开 iPhone 原生全屏版）
- **iPhone 15 Pro 专属版**：`iphone.html`（横竖屏自适应、灵动岛两翼环抱导航、32px 大圆角、3D 翻转）
- **iPhone 1.0 官方存档**：`iphone1.0.html`
- **Web 6.0 桌面官方存档**：`web6.0.html`（3D Cover Flow、看板泳道、闪卡自测、极夜/雅白双主题、Firebase 云同步）

## 🚀 部署与多端访问

已连接 Vercel 自动部署，通过任意手机与电脑浏览器即可访问使用。
